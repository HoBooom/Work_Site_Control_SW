# 0002 GLB 변환을 Blender 대신 파이썬으로

날짜: 2026-11-17
상태: 채택

## 결정

배경 GLB는 `digital-twin/pipeline/glb.py`가 usd-core + numpy로 직접 쓴다. 파이프라인에 Blender를 쓰지 않는다. Blender는 모델링해서 USD로 내보내는 도구로만 쓴다.

## 이유

- 개발용 맥에 Blender가 없고, 파이프라인이 Blender 버전에 묶이지 않는다.
- 같은 USD에서 항상 같은 바이트의 GLB가 나온다(PL-06). `build.py --check`로 결과물이 최신인지 L1에서 확인할 수 있다.
- 색이 같은 형상을 하나로 합쳐 드로우 콜을 줄이는 규칙을 직접 정할 수 있다.

## 한계와 다음

- 지금은 Cube, Mesh와 displayColor만 지원한다. 그 밖의 형상은 validate.py가 막는다.
- M3에서 텍스처·PBR 재질(재질 라이브러리, AS-04)과 meshopt·KTX2 압축(PL-05)이 필요해지면 `@gltf-transform`(Node)을 후처리로 붙이는 것을 먼저 검토한다.
