# 0006 관제 화면 디자인 양식

날짜: 2026-11-19

## 결정

관제 화면(`/`)은 디자인 시안 **Welding Control v3**(claude.ai 디자인 프로젝트 "Welding Control UI mockup")의 배치와 `frontend/DESIGN.md`(흰 바탕, 파랑 하나)의 양식을 따른다. 값은 `frontend/src/app/app.css` 맨 위 CSS 변수에, 2D 상태 색은 `frontend/src/panel/ui-state.ts`에 둔다.

배치(가로 화면):

```
┌ 상태 줄: 로고 · 사이트 이름 ······· 시계 · 연결 상태 · 운영자 ┐
│ 사이드 패널 │손│ 3D 트윈                     [전경|스파이더 1|2] │
│  로봇 목록  │잡│  ┌ 알람 카드 ┐                              │
│  또는 로봇  │이│  └──────────┘      (끊기면 아래에 안내 띠)    │
├ 하단 독: [스파이더 1][스파이더 2][알람 n] ········ [전체 긴급정지] ┤
```

- 사이드 패널은 왼쪽, 기본 폭 440px. 손잡이를 끌어 320px~화면의 62%로 바꾸고, 두 번 누르면 좁게/반반으로 바꾼다(키보드 좌우 화살표도 된다). 세로 화면에서는 트윈이 위, 패널이 아래이고 손잡이는 숨긴다.
- 로봇 패널: 큰 숫자(실행 중·완료·정지면 진행률, 그 밖에는 AI 신뢰도)와 상태 배지·진행 막대·작업 id, 카메라 영상, 신뢰도·추론 지연·외란 강도 칸, 맨 아래 안내 띠와 64px 큰 버튼(수정 / 승인하고 용접 시작, 재작업 / 합격, 재개). "이 로봇 정지"는 패널 머리에 둔다.
- 로봇 이름 밑 작업 이름은 제안의 작업판(`surface`) 이름이다. 계약은 바꾸지 않았다.
- 알람은 트윈 왼쪽 위 카드로 띄우고 하단 독의 알람 버튼으로 연다·닫는다. 치명 알람이 새로 오면 다시 연다.
- 카메라 프리셋은 트윈 오른쪽 위 반투명 버튼 묶음. 로봇을 고르면 그 로봇 프리셋, 풀면 전경으로 간다.
- 브로커와 끊기면 트윈을 회색으로 바꾸고 아래에 안내 띠를 띄운다.

양식:

- 흰 바탕, 회색 면 `#F4F4F4`로 묶고 테두리·그림자를 쓰지 않는다. 글자 `#171A20`, 보조 글자 `#5C5E62`
- 모서리: 버튼·칸 4px, 큰 면(패널·트윈·영상·알람 카드) 12px
- 글꼴 Pretendard, 굵기 400/500만. 대문자 변환 없음
- 손가락 기준: 주 버튼 64px, 하단 독 68px, 그 밖의 버튼 44px 이상

## 관제 화면에 맞게 정한 것

- **파랑(`#3E6AE1`)은 주 동작(승인하고 용접 시작, 합격)에만, 빨강(`#C2261C`)은 멈춤(전체 긴급정지, 이 로봇 정지, 긴급정지·일시정지 상태, 치명 알람)에만 쓴다.** DESIGN.md는 색을 파랑 하나로 두지만, 현장에서 멈춤은 빨강이어야 한다.
- 2D 화면의 상태 색은 v3처럼 흑백(대기 `#5C5E62`, 승인 대기·수정 중·확인 대기 `#171A20`, 실행 중 `#393C41`)에 멈춤만 빨강이다. 상태는 글자(배지·독)로 구별한다.
- **3D 트윈의 상태 색(램프·용접선·알람 마커, `scene/cell-view.ts`)과 영상 위 경로 색(제안 빨강, 완료 초록, 수정 노랑·주황)은 그대로 둔다.** 기능 색이고 트윈 기준 화면(L4)과 묶여 있다.
- 글꼴 Pretendard는 npm 패키지(`pretendard`)의 Regular·Medium(400·500)만 앱에 묶는다. 현장 장비가 인터넷에 못 붙을 수 있어 시안처럼 CDN에서 받지 않는다.
- 트윈 랩(`/lab`)은 개발 도구라 바꾸지 않는다.

## 함께 바꾼 것

주소에 `?site=`가 없을 때 여는 사이트를 `VITE_DEFAULT_SITE`로 정한다(`frontend/.env`는 ship-block). `infra/dev.sh mock <사이트>`는 Mock 서버와 같은 사이트를 넘겨서, `npm run dev` 뒤 `http://localhost:5173/`이 바로 조선소 블록과 거미 로봇을 보여 준다. 코드에는 사이트 이름을 쓰지 않는다(lint 규칙).
