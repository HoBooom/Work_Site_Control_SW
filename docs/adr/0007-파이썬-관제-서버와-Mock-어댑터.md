# 0007 관제 서버를 Python으로 만들고, Mock 어댑터로 Node Mock 서버와 같은 검사를 통과시킨다

날짜: 2026-11-20
상태: 채택

## 결정

- 서버(`server/`)는 Python 3.12+ / FastAPI + uvicorn / paho-mqtt / jsonschema / numpy, 단일 프로세스 asyncio. uv 프로젝트(`server/pyproject.toml`, `uv.lock`)로 관리한다.
- 모듈은 `server/docs/README.md`의 구획(app, bus, task, camera, snap, safety, storage, metrics, adapters, mock)을 그대로 따른다. 상태 전이는 `task/machine.py`(순수 모듈)에서만 일어나고, MQTT는 `bus/`만 안다.
- 메시지 형식은 정의하지 않고 `contracts/`를 읽어 검증한다(보내는 것은 어기면 예외, 받는 명령은 어기면 거부 알람). 타입 생성은 하지 않는다.
- 비전·로봇·카메라는 같은 인터페이스(`adapters/base.py`)의 Mock과 실제 구현을 `--mock vision,robot,camera`로 바꾼다. 팀원 코드는 `adapters/*_real.py`에서만 import한다.
- 검증: 관제 화면 L3(`app.spec.ts`)를 Node Mock 서버(기본)와 이 서버(`WELD_SERVER=python`, `tools/server-process.mjs`가 자식 프로세스로 띄운다) 둘 다로 돌린다. 서버 단위 검사는 pytest(`tests/server/`, L2). L4 패널 기준 화면은 Node Mock으로 찍는다(영상 그림이 같다).
- `infra/dev.sh` 기본 모드를 이 서버로 바꾼다. Node Mock 서버는 `infra/dev.sh mock`으로 남긴다(서버 환경이 없는 사람, 비교용).

## Mock 서버와 다른 점(서버가 더 하는 것)

- 수렴: 확률 맵 위 livewire(`server/docs/snap.md`). Node Mock은 알려진 용접선에 붙인다.
- 정지 뒤 재개: 용접하던 중이면 남은 경로만 다시 제안하고, 진행률은 처음 경로 기준으로 잇는다.
- 장면 변화 감지(SCENE_CHANGED)로 일시정지. 영상이 바뀌는 실제 카메라에서만 돈다.
- 저장(SQLite + 프레임 PNG + 경로 NPY), `/health`, `/api/tasks`.
- 사람이 고친 경로의 신뢰도는 수렴 점수(상한 0.97). Node Mock은 0.97 고정.

## 남은 것

- 실제 어댑터 연결(팀원 비전 모델·로봇 제어 패키지 이름과 시그니처 확인), 카메라 캘리브레이션 파일(`server/calib/{site}.json`)과 절차 문서.
- Jetson(MIC-711D)에서 실행 확인, mosquitto(`infra/mosquitto.conf`)와 함께.
